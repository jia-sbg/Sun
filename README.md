## 📌 简介

一个纯娱乐向的网页小工具，打开即可 **“感受恩情”**。  
内含将军语录、梗图以及 DJ 版 BGM，适合减压、整蛊、朋友间玩笑。

## 📦 本地运行

```bash
git clone https://github.com/jia-sbg/Sun.git
cd Sun
# 使用任意静态服务器，例如：
python -m http.server 8080
```

直接双击 index.html 可能因浏览器安全策略无法自动播放音乐，推荐使用本地服务器或直接访问在线链接。
